# Frontend UI/UX

Act as the design director before writing frontend code.

## Design First

Before implementation, understand:

- What the product does
- Who the users are
- What the page should achieve
- Primary and secondary actions
- Content and information hierarchy
- Appropriate visual personality

Do not immediately start coding.

## Visual Direction

Create a design direction appropriate to the actual product.

Consider:

- Composition
- Typography
- Spacing
- Grid
- Color
- Imagery
- Density
- Interaction
- Motion

Do not force the same aesthetic onto every project.

## Avoid Generic AI Design

Do not default to:

- Centered hero + CTA + image
- Generic 3-column cards
- Excessive rounded cards
- Random gradients
- Glassmorphism everywhere
- Unnecessary bento grids
- Excessive pills, badges, shadows, or effects
- Repetitive section layouts
- Generic SaaS/dashboard aesthetics

Use trends only when they fit the product.

## Inspiration

Use high-quality references such as:

- Awwwards
- shadcn/ui
- Premium product websites
- Strong SaaS and ecommerce interfaces
- Editorial and agency websites

Use references for principles, not for copying.

REFERENCE → ANALYZE → ABSTRACT → CREATE ORIGINAL DESIGN

## UX

Prioritize:

- Clear hierarchy
- Easy navigation
- Obvious actions
- Readability
- Low cognitive load
- Logical grouping
- Useful feedback and states

Visual creativity must never damage usability.

## Component Strategy

Use shadcn/ui and reusable components where appropriate, but do not let the
component library dictate the entire visual identity.

Compose primitives into a product-specific interface.

## Specialist Skills

Use specialist skills when relevant:

- typography
- responsive-design
- layout-composition
- design-inspiration
- shadcn-design-system
- accessibility
- motion-interaction
- visual-qa

## Final Check

Before considering the UI complete, ask:

- Does it feel designed for this product?
- Does it look generic or repetitive?
- Is the hierarchy clear?
- Is the visual direction coherent?
- Does the UX make sense?
- Does the interface feel polished without unnecessary decoration?

If it feels generic, rethink the design direction rather than simply adding
more effects.
